# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or cryptographic weakness in `ample-chat`, please report it responsibly:

- **Do NOT** open a public GitHub issue.
- Please email the maintainers or report via [GitHub Private Vulnerability Reporting](https://github.com/ample-chat/ample-chat/security/advisories/new).
- Include detailed steps to reproduce the issue and an impact assessment.

We take security vulnerabilities seriously and will acknowledge receipt of your report within 48 hours and work with you on a timely resolution prior to public disclosure.
